---

## 一、实验目的

1. 熟练掌握 **Vue3、Bootstrap** 前端框架及 **MVC设计模式** 的实际应用，能基于框架完成前端页面搭建与逻辑开发。
2. 掌握 Vue3 中 **axios** 的使用方法，实现前端与后端的异步数据请求和响应处理。
3. 掌握 **Servlet** 的开发与配置，能够编写Servlet接口为前端提供规范的JSON格式数据。
4. 结合房产销售业务场景，理解**前后端分离**模式下的数据交互流程。

## 四、实验任务（核心功能）

### 4.1 用户角色
| 角色 | 功能 | 固定用户 |
|------|------|----------|
| **普通购房用户** | 浏览、查询、收藏房产，个人信息管理 | 注册用户 |
| **后台管理用户** | 房产CRUD、用户管理、房源审核发布 | admin、zy142857 |

### 4.2 登录/注册流程

#### 注册功能
- 输入项：**邮箱、用户名、密码、确认密码**
- 注册成功后**直接进入滑块验证码验证**（跳过登录步骤）
- 密码使用 **AES加密** 存储

#### 登录功能
- 输入项：**用户名、密码**
- 登录后进入**滑块验证码验证**
- 密码对比前需 **AES解密** 验证

#### 安全防护
- **滑块验证码**防恶意登录
- **所有密码使用AES加密存储**（管理员也无法查看明文）

### 4.3 普通购房用户功能

#### 主界面
- 房产信息**浏览**（卡片列表展示）
- **查询筛选**（按户型、价格、区域等）
- **收藏**（使用 ⭐ 图标）：点击前空心，点击后实心，显示toast提示框（1秒后消失）
- 右上角圆形头像区域（默认空白），点击进入个人主页

#### 个人主页
- 修改用户名、密码、邮箱
- 切换用户按钮（退出登录）
- **圆形头像**：支持图片上传（含gif），自定义模态框裁剪（滚轮缩放+拖动选择区域）
- 返回按钮（🔙）

### 4.4 后台管理用户功能

主界面通过**左侧边栏**切换三栏：

| 栏目 | 功能 |
|------|------|
| **用户信息管理** | 查看所有用户的用户名、绑定邮箱（支持关键字搜索）、加密后的密码 |
| **房源信息CRUD** | 增加(+)、删除(🗑️)、修改(编辑图标)、查找(🔎) |
| **审核发布** | 审核新增房源，卡片显示房源信息 |

**操作说明**：
- 增加房源：点击+后在**自定义模态框**中填写信息
- 删除房源：点击🗑️后弹出**确认模态框**
- 修改房源：点击编辑图标后在**自定义模态框**中编辑
- 所有模态框需**自定义样式**，拥有**关闭按钮**

### 4.5 技术约束
- 基于 **MVC模式** 完成代码与页面组织
- 前后端逻辑解耦，代码结构清晰
- 所有动态数据通过 **axios 请求 Servlet 接口** 获取
- 前端使用 **CDN加载** Vue3、Bootstrap 5、axios，无需Node.js/Vite

## 五、数据库设计

### 5.1 用户表（users）

| 字段名 | 数据类型 | 约束 | 说明 |
|--------|----------|------|------|
| id | INT | PRIMARY KEY, AUTO_INCREMENT | 用户ID |
| username | VARCHAR(50) | NOT NULL, UNIQUE | 用户名 |
| password | VARCHAR(255) | NOT NULL | AES加密后的密码 |
| email | VARCHAR(100) | NOT NULL, UNIQUE | 绑定邮箱 |
| avatar | VARCHAR(255) | NULL | 头像相对路径 |
| role | VARCHAR(20) | NOT NULL, DEFAULT 'user' | 用户角色（user/admin） |
| created_at | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

### 5.2 房产信息表（properties）

| 字段名 | 数据类型 | 约束 | 说明 |
|--------|----------|------|------|
| id | INT | PRIMARY KEY, AUTO_INCREMENT | 房产ID |
| title | VARCHAR(100) | NOT NULL | 房源标题 |
| type | VARCHAR(20) | NOT NULL | 户型（如：三室两厅） |
| area | DECIMAL(10,2) | NOT NULL | 面积（㎡） |
| price | DECIMAL(12,2) | NOT NULL | 价格（万元） |
| region | VARCHAR(50) | NOT NULL | 区域 |
| address | VARCHAR(200) | NOT NULL | 详细地址 |
| description | TEXT | NULL | 房源描述 |
| status | VARCHAR(20) | NOT NULL, DEFAULT 'pending' | 状态（pending/released） |
| created_at | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

### 5.3 收藏表（favorites）

| 字段名 | 数据类型 | 约束 | 说明 |
|--------|----------|------|------|
| id | INT | PRIMARY KEY, AUTO_INCREMENT | 收藏ID |
| user_id | INT | FOREIGN KEY REFERENCES users(id) | 用户ID |
| property_id | INT | FOREIGN KEY REFERENCES properties(id) | 房产ID |
